### MockQueryable / Mocking notes
- MockQueryable 10.0.5:
  - Honors `FirstOrDefaultAsync` (returns first item from seed, ignoring the predicate — so empty seed → null → throw branch).
  - Honors `OrderBy()`, `OrderByDescending()`, `Take()`, `Select()`, `ToListAsync()`.
  - Does not honor complex `Where` predicates reliably — but for simple equality `==` it generally returns the full list. We seed only matching rows so coverage is correct either way.
  - Navigation property access (`d.User.FullName`, `d.Specialty.Name`, `f.Patient.FullName`) reads from in-memory pre-set navigation references — works as long as we manually set the navigation object.
