### MockQueryable / Mocking notes
- MockQueryable 10.0.5:
  - Honors `FirstOrDefaultAsync` (returns first item from seed, ignoring predicate — empty seed → null).
  - Honors `Include(...)` as no-op; navigation properties are accessed via in-memory references (we set them explicitly).
  - Honors `OrderBy()` and `ToListAsync()`.
  - Does not honor complex `Where` predicates reliably — but we seed only matching rows so coverage is correct.
- `MapScheduleDay` is in-memory LINQ over pre-fetched `TimeSlots` collection — full predicate logic applies (no MockQueryable involved). All 3 conditions can be tested independently.
